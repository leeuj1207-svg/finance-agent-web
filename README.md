# Finance Agent Web 1.3

투자·현금성 적립과 지출을 직접 입력하고 기기 내에 보관하는 한국어 정적 웹앱입니다.
기존 CSV 분석·합성 데모·월간 투자 계획 결산도 유지합니다.

기존 주소는 **https://leeuj1207-svg.github.io/finance-agent-web/** 입니다.
이번 변경은 1.3 공개 코드의 검토용 PR이며, 기존 Pages 설정과 주소를 유지합니다.
PR 생성·push·병합으로 실제 사이트를 자동 게시하지 않습니다. 게시에는 별도 사용자 승인이 필요합니다.

## 공개 범위

사이트 실행 파일은 `site/`의 아래 **10개**뿐입니다.

```text
site/
  index.html
  styles.css
  app.js
  core.js
  data.js
  icon.svg
  records.js
  storage.js
  local.js
  .nojekyll
```

그 외에는 기존 README, 민감 파일 제외 규칙, 검사·수동 게시 워크플로만 있습니다.
Python 코드·실제 금융 데이터·CSV 파일·JSON 백업·비밀키·원본 개발 저장소의 Git 이력은
복사하지 않습니다. 공개 커밋은 기존 공개 저장소의 이력만 이어 가며 noreply 작성자 주소를 사용합니다.
`data.js`에는 공개용 기본 투자 계획과 합성 예제만 포함합니다. 코드·계획·예제는 누구나
내려받을 수 있으므로 실제 정보로 바꿔 커밋하지 마세요.

## 1.3 사용법과 저장 위치

지원 대상은 iOS Safari 16.4 이상입니다. **기기 내 기록** 탭에서 날짜·계좌·종목·거래유형·
금액·선택 메모 또는 지출 날짜·가맹점·금액·선택 설명/분류를 입력하고 저장을 확인하세요.
**저장 완료** 표시가 나와야 기기에 반영된 것입니다. 수정·삭제도 확인 후 적용합니다.
지출은 기존 키워드로 자동 분류하며 수동 분류로 수정할 수 있습니다.
월 목표 126만원(매수 118만원·현금성 적립 8만원)과 기존 계좌/종목/자산군 계산을 유지합니다.

직접 입력 기록은 **이 기기의 이 출처(프로토콜·호스트·포트)의 브라우저 IndexedDB**에만
저장합니다. 새로고침 후 유지되며 서버 업로드·로그인·기기간 자동 동기화는 없습니다.
같은 출처의 다른 코드도 접근할 수 있으므로 기기와 배포 코드를 신뢰할 수 있어야 합니다.
Safari 저장소 정리·사생활 보호 모드·사이트 데이터 삭제·기기 변경/분실로 유실될 수 있습니다.
정기적으로 백업하고 기기를 넘기기 전 저장 기록과 Safari 사이트 데이터를 정리하세요.
지원 불가·용량 부족·동시 탭 충돌은 오류로 표시하며 무음으로 메모리에 대체 저장하지 않습니다.

## JSON 백업·복원

**전체 기록 JSON 백업**은 모든 월의 직접 입력과 식별자·스키마 버전·생성 시각을 포함합니다.
Safari에서 다운로드가 열리면 공유 메뉴의 **파일에 저장**을 완료하세요.
백업은 **암호화되지 않은 파일**이며 가맹점·메모 등 민감정보를 포함할 수 있습니다.
공유하거나 공개 저장소·Issue·PR·Actions에 업로드하지 말고 개인 저장 공간에 보관하세요.

복원은 최대 2MB·10,000건, 형식·금액·날짜·중복을 검증한 뒤 미리보기를 제공합니다.
**병합** 또는 **전체 교체**를 직접 선택하고 확인해야 저장합니다.
병합은 동일 거래를 한 번만 유지하며 내용 충돌은 거부합니다.
전체 교체는 선택 월과 관계없이 모든 월을 교체하며 빈 백업은 전체 삭제입니다.
단일 IndexedDB 트랜잭션으로 처리해 실패하면 원본을 보존합니다.
다른 탭을 사용했다면 새로고침하여 최신 기록을 읽은 뒤 백업하세요.

## CSV와 합성 데모

**합성 데모로 둘러보기**는 2026년 1월 예제입니다. 투자/지출 화면에서 UTF-8 CSV도
선택할 수 있습니다. CSV와 데모는 임시 분석이며 영구 저장하거나 직접 입력으로 가져오지 않습니다.
**기록 지우기**는 임시 분석만 지우며 저장 기록은 삭제하지 않습니다. 월 선택·데모 전환도
저장 기록을 변경하지 않습니다. **저장 기록으로 분석 보기**로 다시 전환할 수 있습니다.

- 투자 CSV 필수 열: `date,account,symbol,amount`, 선택 열: `kind,transaction_id`.
- 계좌 별칭: `new_funds`, `pension`, `irp`, `isa`.
- 현금성 적립: `new_funds` 계좌의 `CASH-RESERVE`, `kind=reserve`. 매수와 별도 집계합니다.
- 지출 CSV 필수 열: `date,merchant,amount,description`. 설명은 비워도 됩니다.
- CSV는 파일당 2MB, UTF-8 BOM·인용부호를 지원하며 XLSX는 미지원입니다.

기존 CSP의 `connect-src 'none'`과 `form-action 'none'`을 유지합니다.
입력·분석·저장·백업은 브라우저에서만 처리하며 외부 추적·API·서버 업로드가 없습니다.
첫 화면을 받을 연결은 필요합니다. 서비스 워커·오프라인 최초 실행은 지원하지 않습니다.
호스팅 서비스는 방문 IP 등 접속 메타데이터를 수집할 수 있습니다.

Pages 권한은 배포 작업에만 있고 자동 활성화하지 않습니다.
